# Data Cleaning

Data Cleaning is the process of fixing mistakes and inconsistencies in your dataset before using it in a machine learning model.  
You can say: **EDA tells you what's wrong. Data Cleaning fixes it.**  
Although not glamorous, cleaning is often **80% of the work** in real-world ML projects.

---

## 🛠️ Steps in Data Cleaning

### 1. Handle Missing Values
- Check which columns have missing values (nulls).
- Strategies:
  - Drop missing rows/columns (only if very few).
  - Impute with:
    - Mean/Median → for numerical data
    - Mode → for categorical data
    - Advanced: Linear regression, KNN, or interpolation

---

### 2. Remove Duplicates
- Detect and drop exact duplicate rows.

---

### 3. Fix Data Types
- Convert wrong types (e.g., numbers stored as strings, dates as text).

---

### 4. Handle Inconsistent Categories
- Clean up categorical values:
  - `"Male", "male", "MALE"` → unify to `"male"`
  - `"Yes", "yes", "Y"` → unify to one format

---

### 5. Detect and Handle Outliers
- Use boxplots, IQR, or Z-score.
- Handle by:
  - Removing (if clearly wrong)
  - Capping (e.g., to 95th percentile)

---

### 6. Fix Logic or Domain Errors
- Examples:
  - `age = -5` is invalid
  - `BMI = 150` likely an error
- Replace with mean/median or remove.

---

## 🚀 Summary
- Data Cleaning ensures your dataset is **accurate, consistent, and usable**.  
- It prepares the foundation for preprocessing, feature engineering, and model building.
