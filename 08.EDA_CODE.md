
# Exploratory Data Analysis (EDA)

Exploratory Data Analysis (EDA) is the process of analyzing datasets to summarize their main characteristics, often using visual methods.  
It helps you understand the structure, detect anomalies, and discover patterns before applying machine learning.

---

## 📂 Example Dataset (`students.csv`)
```csv
Name,Age,Marks,Gender
Amit,20,85,Male
Priya,22,90,Female
Rahul,21,70,Male
Sneha,23,95,Female
Arjun,20,60,Male
```

---

## 🛠️ EDA Commands with Outputs

### 1. Load and View Data
```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.read_csv("students.csv")
print(df.head())
```

**Output:**
```
    Name  Age  Marks  Gender
0   Amit   20     85    Male
1  Priya   22     90  Female
2  Rahul   21     70    Male
3  Sneha   23     95  Female
4  Arjun   20     60    Male
```

```python
print(df.shape)
```

📊 Histogram → Marks distribution (peaks around 85–95).

📊 Boxplot → Female students have slightly higher marks.

```python
sns.scatterplot(x='Age', y='Marks', data=df)

```
📊 Scatter plot → No strong trend between Age and Marks.

## 🚀 Summary
EDA helps you:
- Understand dataset structure (`head()`, `info()`, `describe()`).
- Detect missing values and duplicates.
- Explore distributions and relationships.
- Visualize patterns with histograms, boxplots, scatterplots, and heatmaps.

# 🧹 Data Cleaning

Data Cleaning is the process of fixing mistakes and inconsistencies in your dataset before using it in a machine learning model.  
Think of it as: **EDA tells you what’s wrong, Data Cleaning fixes it.**

---

## Example Dataset (`students_dirty.csv`)
```csv
Name,Age,Marks,Gender
Amit,20,85,Male
Priya,,90,Female
Rahul,21,70,Male
Sneha,23,,Female
Arjun,20,60,Male
Rahul,21,70,Male   # duplicate row
```

---

## 🛠️ Data Cleaning in Python

```python
import pandas as pd

df = pd.read_csv("students_dirty.csv")

# 1. Check missing values
print(df.isnull().sum())
```

**Output:**
```
Name     0
Age      1
Marks    1
Gender   0
dtype: int64
```

---

```python
# 2. Handle missing values
df['Age'].fillna(df['Age'].mean(), inplace=True)   # impute with mean
df['Marks'].fillna(df['Marks'].median(), inplace=True)  # impute with median
```

---

```python
# 3. Remove duplicates
df = df.drop_duplicates()
```

---

```python
# 4. Fix inconsistent categories
df['Gender'] = df['Gender'].str.lower()   # convert to lowercase
```

---

```python
# 5. Check cleaned data
print(df)
```

**Output:**
```
    Name   Age  Marks  Gender
0   Amit  20.0   85.0    male
1  Priya  21.0   90.0  female
2  Rahul  21.0   70.0    male
3  Sneha  23.0   90.0  female
4  Arjun  20.0   60.0    male
```

✅ Dataset is now clean: no missing values, no duplicates, consistent categories.

---

# 🔄 Data Preprocessing

Data Preprocessing prepares clean data so it can be analyzed or used in a machine learning model.  
If **Data Cleaning** fixes mistakes, **Preprocessing** transforms valid data into usable format.

---

## 🛠️ Data Preprocessing in Python

### 1. Encoding Categorical Variables
```python
from sklearn.preprocessing import LabelEncoder, OneHotEncoder

# Label Encoding (Ordinal)
le = LabelEncoder()
df['Gender_Label'] = le.fit_transform(df['Gender'])
print(df[['Gender','Gender_Label']])
```

**Output:**
```
   Gender  Gender_Label
0    male             1
1  female             0
2    male             1
3  female             0
4    male             1
```

---

```python
# One-Hot Encoding (Nominal)
df_onehot = pd.get_dummies(df['Gender'], prefix='Gender')
print(df_onehot.head())
```

**Output:**
```
   Gender_female  Gender_male
0              0            1
1              1            0
2              0            1
3              1            0
4              0            1
```

---

### 2. Feature Scaling
```python
from sklearn.preprocessing import MinMaxScaler, StandardScaler

scaler = MinMaxScaler()
df['Marks_Normalized'] = scaler.fit_transform(df[['Marks']])

scaler = StandardScaler()
df['Marks_Standardized'] = scaler.fit_transform(df[['Marks']])

print(df[['Marks','Marks_Normalized','Marks_Standardized']])
```

**Output:**
```
   Marks  Marks_Normalized  Marks_Standardized
0   85.0          0.625000           0.904534
1   90.0          0.750000           1.507557
2   70.0          0.250000          -0.301511
3   90.0          0.750000           1.507557
4   60.0          0.000000          -1.507557
```

---

## 🚀 Summary
- **Data Cleaning** → Fix missing values, duplicates, inconsistent categories.  
- **Data Preprocessing** → Encode categorical variables, scale numerical features.  
- Together, they prepare your dataset for **Feature Engineering → Feature Selection → Modeling**.
