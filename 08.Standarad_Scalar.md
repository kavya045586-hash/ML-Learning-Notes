
# StandardScaler

StandardScaler is a preprocessing technique that transforms numerical features so they have:
- **Mean = 0**
- **Standard Deviation = 1**

This is also called **Z-score normalization**.

---


## 📂 Example Dataset (`students_height_weight.csv`)
```csv
Height,Weight
150,50
160,60
170,65
180,80
190,90
```

---

## 🐍 Python Example
```python
import pandas as pd
from sklearn.preprocessing import StandardScaler

# Sample dataset
data = {'Height':[150,160,170,180,190],
        'Weight':[50,60,65,80,90]}
df = pd.DataFrame(data)

print("Original Data:\n", df)

# Apply StandardScaler
scaler = StandardScaler()
scaled = scaler.fit_transform(df)

scaled_df = pd.DataFrame(scaled, columns=['Height_scaled','Weight_scaled'])
print("\nScaled Data:\n", scaled_df)
```

---

## 🚀 Why Use StandardScaler?
- Ensures features are on the same scale → avoids bias in distance-based models (KNN, SVM).  
- Speeds up convergence in gradient descent (Logistic Regression, Neural Networks).  
- Makes coefficients more interpretable in linear models.  

---

✅ **Key takeaway:**  
Use **StandardScaler** whenever your model relies on distances or gradients.  
Skip it for tree-based models (Decision Trees, Random Forests) since they don’t depend on feature scaling.
