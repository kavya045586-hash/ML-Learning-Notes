# Data Preprocessing

Data Preprocessing prepares clean data so it can be analyzed or used in a machine learning model.  
If **Data Cleaning** is about fixing mistakes, **Data Preprocessing** is about transforming valid data into a usable format.

---

## 🛠️ Steps in Data Preprocessing

### 1. Encoding Categorical Variables
Convert text labels (like `"male"`, `"yes"`, `"southeast"`) into numbers.

**Two common methods:**

#### 🔤 Label Encoding (Ordinal)
- Best for ordered categories (Low < Medium < High).
- Each category is converted into an integer.

**Example: Education Level**
| Education     | Encoded |
|---------------|---------|
| High School   | 0       |
| Bachelor      | 1       |
| Master        | 2       |
| PhD           | 3       |

👉 Numbers preserve the order (PhD > Master > Bachelor > High School).

---

#### 🟦 One-Hot Encoding (Nominal)
- Best for non-ordered categories (like regions, colors).
- Each category becomes a separate column with binary values (0/1).

**Example: Region**
| Region | North | South | East | West |
|--------|-------|-------|------|------|
| North  | 1     | 0     | 0    | 0    |
| South  | 0     | 1     | 0    | 0    |
| East   | 0     | 0     | 1    | 0    |
| West   | 0     | 0     | 0    | 1    |

👉 No order is implied; each region is represented independently.

---

### 2. Feature Transformation
- Apply transformations (Log, Square root, etc.) to handle skewed data.  
- Useful for right-skewed or left-skewed distributions.

---

### 3. Feature Scaling
Bring numerical values to the same scale — especially useful for distance-based algorithms.

- **Normalization (Min-Max Scaling):**  
  Scales values between 0 and 1.
  
- **Standardization (Z-score Scaling):**  
  Transforms data to have mean = 0 and standard deviation = 1.

---

## 🚀 Summary
Data Preprocessing ensures that your dataset is in the **right format** for machine learning models.  
It transforms categorical, skewed, or scaled data into a consistent structure that algorithms can learn from effectively.
