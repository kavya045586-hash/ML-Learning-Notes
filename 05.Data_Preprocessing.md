# Data Preprocessing

Data Preprocessing prepares clean data so it can be analyzed or used in a machine learning model.  
If **Data Cleaning** is about fixing mistakes, **Data Preprocessing** is about transforming valid data into a usable format.

---

## 🛠️ Steps in Data Preprocessing

### 1. Encoding Categorical Variables
Convert text labels (like `"male"`, `"yes"`, `"southeast"`) into numbers.

**Two common methods:**

#### 🔤 Label Encoding (Ordinal)
- Best for ordered categories (Low < Medium < High).
- Each category is converted into an integer.

**Example: Education Level**
| Education     | Encoded |
|---------------|---------|
| High School   | 0       |
| Bachelor      | 1       |
| Master        | 2       |
| PhD           | 3       |

👉 Numbers preserve the order (PhD > Master > Bachelor > High School).

---

#### 🟦 One-Hot Encoding (Nominal)
- Best for non-ordered categories (like regions, colors).
- Each category becomes a separate column with binary values (0/1).

**Example: Region**
| Region | North | South | East | West |
|--------|-------|-------|------|------|
| North  | 1     | 0     | 0    | 0    |
| South  | 0     | 1     | 0    | 0    |
| East   | 0     | 0     | 1    | 0    |
| West   | 0     | 0     | 0    | 1    |

👉 No order is implied; each region is represented independently.

---

### 2. Feature Transformation
- Apply transformations (Log, Square root, etc.) to handle skewed data.  
- Useful for right-skewed or left-skewed distributions.

---

### 3. Feature Scaling
Feature scaling ensures numerical values are on comparable ranges, which is crucial for algorithms that rely on distances (like KNN, SVM) or gradient descent (like Logistic Regression, Neural Networks).

---

#### 🔹 Normalization (Min-Max Scaling)



- Scales values between **0 and 1**.

**Example: Ages**
Original values: `[20, 30, 40, 50]`  


| Age | Normalized |
|-----|------------|
| 20  | 0.0        |
| 30  | 0.33       |
| 40  | 0.67       |
| 50  | 1.0        |

👉 All values are now between 0 and 1.

---

#### 🔹 Standardization (Z-score Scaling)


- Transforms data to have **mean = 0** and **standard deviation = 1**.

**Example: Exam Scores**
Original values: `[50, 60, 70, 80]`  
- Mean () = 65  
- Standard deviation () ≈ 11.18  

| Score | Standardized |
|-------|--------------|
| 50    | -1.34        |
| 60    | -0.45        |
| 70    | 0.45         |
| 80    | 1.34         |

👉 Values are centered around 0, with spread adjusted by standard deviation.

---

#### ⚡ Quick Comparison
| Method          | Range | Best For |
|-----------------|-------|----------|
| Normalization   | [0, 1] | When you know the min/max and want bounded values (e.g., image pixel values). |
| Standardization | Mean=0, Std=1 | When data has varying scales and you want to normalize distribution (e.g., regression, PCA). |

---

✅ **Key takeaway:**  
- Use **Normalization** when you want values strictly between 0 and 1.  
- Use **Standardization** when you want to center data and handle varying distributions.
