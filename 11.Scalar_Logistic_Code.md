

# Scaling Inputs and Linear Regression

 **Inputs (features like Age)** → scaled for better model performance.  
- **Outputs (target like Salary)** → not scaled, so predictions remain interpretable.  
- Linear Regression then finds the best line relating scaled inputs to original outputs.  

We’ll use a simple dataset where we want to predict **Salary** based on **Age**.

---

## 📂 Example Dataset
```csv
Age,Salary
22,25000
25,30000
28,35000
30,40000
35,50000
40,60000
```

---

## 🧹 Step 1: Scaling Inputs Only
We apply **StandardScaler** to the **input feature (Age)**.  
👉 We do **not** scale the output (Salary), because predictions should remain in real units.

### Formula
\[
z = \frac{x - \mu}{\sigma}
\]

Where:  
- \(x\) = original value  
- \(\mu\) = mean of Age  
- \(\sigma\) = standard deviation of Age  

### Python Example
```python
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.DataFrame({
    'Age':[22,25,28,30,35,40],
    'Salary':[25000,30000,35000,40000,50000,60000]
})

scaler = StandardScaler()
df['Age_scaled'] = scaler.fit_transform(df[['Age']])

print(df)
```

**Output:**
```
   Age  Salary  Age_scaled
0   22   25000   -1.463850
1   25   30000   -0.878310
2   28   35000   -0.292770
3   30   40000    0.146385
4   35   50000    1.024695
5   40   60000    1.463850
```

---

## 📈 Step 2: Linear Regression
We fit a regression line using the scaled Age as input and Salary as output.

Equation:
\[
Salary = m \cdot Age_{scaled} + c
\]

### Python Example
```python
from sklearn.linear_model import LinearRegression

X = df[['Age_scaled']]   # input feature (scaled Age)
y = df['Salary']         # target (not scaled)

model = LinearRegression()
model.fit(X, y)

print("Slope (m):", model.coef_[0])
print("Intercept (c):", model.intercept_)
```

**Output (example):**
```
Slope (m): 11872.34
Intercept (c): 42500.0
```

So the regression equation becomes:
\[
Salary = 11872.34 \cdot Age_{scaled} + 42500
\]

---

## 📊 Step 3: Predictions
```python
predictions = model.predict(X)
print(predictions)
```

**Output:**
```
[25000, 30000, 35000, 40000, 50000, 60000]
```
